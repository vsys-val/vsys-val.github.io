MétodoMethod

01

Meu método cabe em seis linhas, e a ordem importa: cada uma só faz sentido depois da anterior. Não é filosofia. É o que eu faço antes de abrir o editor. My method fits in six lines, and the order matters: each one only makes sense after the one before it. It isn't philosophy. It's what I do before opening the editor.

  1. 01

    Problema antes da soluçãoProblem before solution

    Se ninguém consegue dizer qual dor está sendo resolvida, o projeto já começou torto. Eu pergunto até ficar chato. É mais barato ser chato na reunião de escopo do que na entrega. If nobody can say which pain is being solved, the project already started crooked. I keep asking until it gets annoying. Being annoying in the scoping meeting is cheaper than being annoying at delivery.

  2. 02

    Risco antes do documentoRisk before paperwork

    Documento que não muda uma decisão é decoração com frontmatter. Primeiro identifico o que pode dar errado e quanto custa; o artefato existe pra endereçar isso, não pra encher pasta. A document that changes no decision is decoration with frontmatter. First I name what can go wrong and what it costs; the artifact exists to address that, not to fill a folder.

  3. 03

    Métrica antes do MVPMetric before MVP

    Entregar rápido é fácil. Entregar algo que dá pra medir depois é o que separa protótipo de produto. Se não dá pra dizer como saberemos que funcionou, ainda não é escopo. Shipping fast is easy. Shipping something you can measure afterwards is what separates a prototype from a product. If we can't say how we'll know it worked, it isn't scope yet.

  4. 04

    Simples o bastante para aguentarSimple enough to hold

    A solução certa é a mais simples que sustenta o problema real, não a mais elegante que eu saberia construir. Abstração que ninguém pediu é dívida técnica com boas intenções. The right solution is the simplest one that holds the real problem, not the most elegant one I could build. An abstraction nobody asked for is technical debt with good intentions.

  5. 05

    Honestidade cedoHonesty, early

    Prefiro a conversa desconfortável no dia 3 à surpresa no dia 30. Se o prazo não fecha, digo antes; se eu não sei, digo que não sei e volto com resposta. I'd rather have the uncomfortable conversation on day 3 than the surprise on day 30. If the deadline doesn't hold, I say so early; if I don't know, I say I don't know and come back with an answer.

  6. 06

    Produção exige operaçãoProduction needs operating

    Deploy não é entrega. Quem recebe precisa saber o que mudou, o que pode quebrar e como voltar atrás, além de log e de um jeito de perceber a falha antes do cliente perceber. A deploy isn't a delivery. Whoever receives it needs to know what changed, what can break and how to roll back, plus logs and a way to notice the failure before the customer does.

fastapi-merchant-app Caso 01Case 01

API em produção · PythonLive API · Python

API de catálogo de produtos e avaliações de consumidores. Rodando em produção no Render, com PostgreSQL no Supabase. Não é projeto de pasta local. An API for a product catalog and consumer reviews. Running in production on Render with PostgreSQL on Supabase. Not a local-folder project.

DecisãoDecision

Credenciais separadas: um papel administrativo só para migrações, e outro de privilégio mínimo para o runtime, com RLS ligado nas tabelas de negócio e internas. Split credentials: an admin role for migrations only, and a least-privilege role for runtime, with RLS enabled on business and internal tables.

RiscoRisk

Uma falha na camada da API não pode virar acesso irrestrito ao banco. Se a aplicação cair, o estrago para no papel que ela usa. A flaw in the API layer must not become unrestricted database access. If the app is compromised, the blast radius stops at the role it runs as.

EvidênciaEvidence

127 testes automatizados, smoke test diário contra a API publicada e rate limit de login atômico resolvido no próprio Postgres, não em memória. 127 automated tests, a daily smoke test against the published API, and atomic login rate limiting solved in Postgres itself, not in memory.

job-market-monitor Caso 02Case 02

Pipeline de dados · PythonData pipeline · Python

Coletor de vagas remotas da área de dados: consome duas APIs públicas, normaliza para um modelo único, guarda em SQLite e exporta CSV. Nasceu de um problema meu: procurar estágio. A collector for remote data-role job posts: reads two public APIs, normalizes them into one model, stores in SQLite and exports CSV. It came from a problem of my own: looking for an internship.

DecisãoDecision

Deduplicação por URL na camada de persistência, não no consumo. Um filtro local compensa o comportamento inconsistente de uma das APIs. Deduplication by URL at the persistence layer, not at read time. A local filter compensates for one API's inconsistent behavior.

RiscoRisk

As duas fontes publicam a mesma vaga. Contar duas vezes envenena qualquer análise feita depois, e ninguém percebe até a conclusão estar errada. Both sources publish the same posting. Counting it twice poisons every later analysis, and nobody notices until the conclusion is wrong.

EvidênciaEvidence

Histórico de execuções com timestamp, log em terminal e arquivo, tratamento de falha de requisição e suíte de testes em Pytest. Timestamped run history, terminal and file logging, graceful request-failure handling, and a Pytest suite.

  • Python 3.12
  • SQLite
  • Pandas
  • Requests
  • Pytest
  • CLI

ForHouseCaso 03Case 03

Java · Spring · projeto em grupoJava · Spring · team project

Plataforma de intermediação de serviços domésticos, feita em grupo na UERJ: API em Spring Boot, protótipo navegável de 18 telas e documentação de modelagem. A home-services marketplace built with a team at UERJ: a Spring Boot API, an 18-screen clickable prototype and full modeling documentation.

DecisãoDecision

O enum de situação do agendamento é ao mesmo tempo a coluna persistida e a fábrica do objeto de estado; o estado vive como @Transient, reconstruído no @PostLoad. The booking-status enum is both the persisted column and the factory for the state object; the state itself is @Transient, rebuilt on @PostLoad.

RiscoRisk

Mapear cinco classes de estado como entidades só para satisfazer o padrão State: banco poluído, migração cara, nenhum ganho real. Mapping five state classes as entities just to satisfy the State pattern: a polluted schema, expensive migrations, no real gain.

EvidênciaEvidence

open-in-view desligado e conversão entidade→DTO dentro da transação: corrigiu um LazyInitializationException real. O domínio não importa nada do framework, então roda em teste puro. open-in-view disabled and entity→DTO conversion inside the transaction: fixed a real LazyInitializationException. The domain imports nothing from the framework, so it runs in plain unit tests.

SobreAbout

04

Gosto mais de entender por que uma coisa quebra do que de fazer ela funcionar de primeira. I'm more interested in why something breaks than in making it work on the first try.

Estou no sétimo período de Ciência da Computação na UERJ. No caminho, descobri que a parte que mais me interessa não é a mais difícil tecnicamente. É a conversa antes do código: entender o negócio, achar a dor de verdade e escolher a solução mais simples que aguenta o problema. I'm in the seventh semester of Computer Science at UERJ. Along the way I found that the part that interests me most isn't the technically hardest one. It's the conversation before the code: understanding the business, finding the actual pain, and picking the simplest solution that holds the problem.

Isso acabou virando método, e o método acabou virando ferramenta. Provavelmente diz mais sobre mim do que qualquer lista de tecnologia. Trabalho bem quando o prazo é claro, o escopo é honesto e alguém do outro lado quer o problema resolvido, não impressionado. That turned into a method, and the method turned into tooling. It probably says more about me than any tech list. I work well when the deadline is clear, the scope is honest, and someone on the other side wants the problem solved, not flattered.
